# FINOS Workspace

FINOS Workspace is an open, self-hosted analytics workspace for financial institutions. Users connect their own data backends and arrange the data in dashboards of widgets. An AI agent can read the dashboards and answer questions about them, and external AI tools can work with them through an MCP server. Admins decide who may use what through roles, and plugins add new kinds of widgets.
