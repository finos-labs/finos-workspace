# FINOS Workspace

FINOS Workspace is an open, self-hosted analytics workspace for financial institutions. You connect your own data backends, arrange their data in dashboards of widgets, and save dashboards as apps that others can open. An AI Agent reads your dashboards and answers questions about them, and the MCP Companion lets your own AI tools work with them.
