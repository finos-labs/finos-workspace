# FINOS Workspace MCP server

FINOS Workspace includes an MCP server. An AI tool outside the app uses this server to read and change a user's dashboards.

- Each tool of the server works through a FINOS Workspace tab that the user connected. [MCP Companion](../index.mdx) explains why.
- The API serves the server at `/mcp`. The code is in `backend-api/backend/workspace_mcp`.
- The AI tool identifies the user with a personal access token. The user creates the token in the app, as [Connect your AI tool](../connect-your-ai-tool.mdx) shows.

This page lists what the server gives to an AI tool:

1. **Instructions.** The server sends this text to each AI tool when it connects. The text describes the conventions and the recommended order of the calls.
2. **Tools, resources and prompts.** Each one has its arguments and its description.

The docs generator builds this page from `backend-api/backend/tests/fixtures/workspace_mcp_sidecar_surface.json`. A test makes sure that this file agrees with the server.
