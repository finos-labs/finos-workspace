# Dashboard

A dashboard arranges widgets on a page. Each widget on it is a card.

- A dashboard has a grid that is 40 columns wide, and one or more tabs.
- Each card keeps its own size, place, parameter values and settings. The same [widget](widget.md) can be on many dashboards, or several times on one.
- Parameters of different cards can be linked, so that a change in one card moves the others.
- A dashboard stores the arrangement and the values, not the data. The browser asks the connectors each time the dashboard opens.
- A dashboard belongs to one person. The FINOS Workspace API stores it and keeps older versions for a while.
- A dashboard can be saved as an [app](app.md), shared and exported.
