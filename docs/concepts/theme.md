# Theme

A theme sets the colors and the font of the web app. The app has a light and a dark theme.

- A theme is a stylesheet that you give the web app, or a preset that an admin designs in the app.
- A theme needs to hold only the properties that you change.
- White label goes further: your own name, logos and images.

- **Use it:** [Design and apply a theme in the admin area](../features/administration/design-a-theme-in-the-admin-area.mdx), [Create a theme for the web app](../features/white-label/create-a-theme.md), [White label](../features/white-label/index.md)
- **Look it up:** [Theme presets](../reference/css/theme-presets.mdx), [Styling surfaces](../reference/css/styling-surfaces.mdx)
