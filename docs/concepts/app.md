# App

An app is a template for dashboards. It remembers which widgets to place, where, and with which parameter values and links. It can also carry suggested questions for the [Agent](agent.md).

- Opening an app creates a new [dashboard](dashboard.md) from it. The new dashboard belongs to the person who opened it.
- A [connector](connector.md) can offer apps in its `apps.json`.
- A person can save a dashboard of their own as an app. It carries the tag Saved App.
- Both kinds appear on the Apps page.
