# Technical Guide

This guide is for the people who deploy, configure and extend FINOS Workspace: operators, platform teams and backend developers.

- **[Architecture](architecture/index.mdx):** the services and how the browser connects them.
- **Build from source:** run the stack from source, build the images, and the supply chain behind them.
- **Deploy:** the production setup, database and cache, file storage, HTTPS, scaling, logs, metrics and traces, single sign-on.
- **Configure:** the Copilot model, document search, dictation and themes.
- **[Build a backend](build-a-backend/reference-backend.md):** serve widgets and apps from your own data, starting from the reference backend.
- **[Reference](reference/index.md):** every setting, API, schema and protocol, generated from the code.
