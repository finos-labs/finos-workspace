# User Guide

This guide is for people who use FINOS Workspace day to day: building dashboards, working with apps, and asking the Copilot. It assumes someone has already [started FINOS Workspace](../quick-start.mdx) and connected a backend.

## Get started

- [The building blocks](primitives.md): widgets, dashboards, apps, backends and the Copilot, and how they fit together.
- [Create and arrange dashboards](dashboards/create-and-arrange-dashboards.md)
- [Widget types](widgets/widget-types.md)
- [Ask the Copilot about a dashboard](copilot/ask-the-copilot-about-a-dashboard.md)

## Areas

- **Dashboards:** create, organize in folders, export.
- **Widgets:** the widget types, files as widgets, web pages, linked parameters.
- **Apps:** open an app, save a dashboard as an app.
- **Data backends:** connect your own data.
- **Copilot:** ask questions, attach files, dictate, prompts, skills, extra tools from MCP servers.
- **Sharing:** share dashboards and approve share requests.
- **Account:** settings and two-factor sign-in.
- **Administration:** users, roles, data access and the theme, for organization admins.
