# How to save a dashboard as an app

An app is a dashboard that you keep as a template. It remembers which widgets are on the dashboard, how they are arranged and the values of their parameters, and it can carry suggested prompts for the Copilot. This guide saves a dashboard as an app, keeps the app up to date, gives it suggested prompts, and opens it again.

## Save the dashboard

1. Right-click the dashboard in the sidebar, or select the three dots that appear next to it, and choose Save App. The dialog is titled Save App from Dashboard.
2. Check the Name, which starts as the dashboard's name. A new app needs a name that no other app of yours has.
3. Write a Description. Both the name and the description are required.
4. Optionally, give an Image cover. It is the address of a picture, and the card of the app shows it.
5. Optionally, add prompts, as the next section describes.
6. Select Save.

The App Preview on the right shows the card as it will look, with the number of widgets and of prompts. When the save works, a message says "App created successfully!" and that the app has been saved to your apps. A dashboard that has no widgets cannot be saved, and FINOS Workspace says "Dashboard must contain at least one widget".

## Update an app instead of creating another

Once you have an app, the dialog offers two choices at its top: Save as new app and Update existing app. Choose Update existing app and pick the app in the list that appears. FINOS Workspace then replaces the app's widgets, layout and parameter values with those of the dashboard, together with the name, description, image and prompts that you give. A message says "App updated successfully!".

When the dashboard was itself opened from one of your apps, the dialog starts on Update existing app with that app selected, and it says "Dashboard already saved". Choose Save as new app when you want a second app.

## Add prompts

Prompts are suggestions that the Copilot shows when somebody uses a dashboard that was made from the app. In the section Prompts of the dialog, select New prompt, type the question, and select Add. The counter shows how many of the <WebAppValue of="maxAppPrompts" /> allowed you have used, and a prompt can have up to <WebAppValue of="maxAppPromptLength" /> characters. Shift+Enter starts a new line inside a prompt, and the cross at the end of a prompt removes it.

When somebody opens the app and starts a chat, the Copilot panel says "Get started with these suggested prompts for this dashboard" and lists the prompts. Selecting one asks it.

## Open an app

Select Apps in the sidebar. The page lists your apps and the apps that your organization provides as cards. Each card has the tag Saved App when you created it, its name and description, and the number of widgets and of prompts. The search box, the backend and app filters and the sort menu narrow the list, and the refresh button loads it again.

Select a card to open the app. FINOS Workspace creates a new dashboard from it, with the widgets in the same places, and opens that dashboard.

## Edit, delete or share an app

The three dots on a card open a menu with Edit and Delete. Edit opens the dialog Edit App, where you change the name, description, image and prompts and select Save Changes. It does not change the widgets, which only Update existing app does. Delete asks "Are you sure you want to delete" the app and says that the action cannot be undone, and it removes the app when you confirm. The share icon at the bottom right of a card shares the app, as [How to share a dashboard](../sharing/share-a-dashboard.md#share-an-app) describes, and the card of an app that you shared shows the initials of the people who have access.
