# Parameters

Parameters are the controls in a widget's header. FINOS Workspace sends their values with each request: in the query by default, or in a header, a JSON body or the path. The `type` of a parameter decides the control, so pick the type that matches the value. [widgets.json](../../reference/schemas/widgets-json.mdx) lists every field, and [Widget requests](../../reference/protocols/widget-requests.mdx) lists how each value is written and which values are not sent.

## Text parameter

A `text` parameter is a text box. An empty value is not sent, so the route needs a default.

```json title="widgets.json"
{
  "param_text": {
    "name": "Text parameter",
    "description": "A text box whose value the backend echoes",
    "category": "Reference backend",
    "subCategory": "Parameters",
    "type": "markdown",
    "endpoint": "param_text",
    "gridData": {
      "w": 20,
      "h": 8
    },
    "source": "Invented sample data",
    "params": [
      {
        "paramName": "name",
        "type": "text",
        "label": "Name",
        "description": "A name to greet",
        "value": "Analyst",
        "placeholder": "Type a name"
      }
    ]
  }
}
```

```python title="python/main.py"
@app.get("/param_text")
def param_text(name: str = "") -> PlainTextResponse:
```

## Boolean parameter

A `boolean` parameter is a toggle, sent as `true` or `false`. A default of `false` is sent too.

```json title="widgets.json"
{
  "param_boolean": {
    "name": "Boolean parameter",
    "description": "A toggle that shows or hides the details of each company",
    "category": "Reference backend",
    "subCategory": "Parameters",
    "type": "markdown",
    "endpoint": "param_boolean",
    "gridData": {
      "w": 20,
      "h": 10
    },
    "source": "Invented sample data",
    "params": [
      {
        "paramName": "include_details",
        "type": "boolean",
        "label": "Include details",
        "description": "Show the sector and headquarters",
        "value": false
      }
    ]
  }
}
```

<TabItem value="python" label="Python">

```python title="python/main.py"
@app.get("/param_boolean")
def param_boolean(include_details: bool = False) -> PlainTextResponse:
    lines = [
        f"- **{c['name']}**"
        + (f": {c['sector']}, {c['headquarters']}" if include_details else "")
        for c in DATA["companies"]
    ]
    return markdown("\n".join(lines))
```

</TabItem>

```ts title="typescript/main.ts"
"/param_boolean": ({ query }) => {
  const details = flag(query.get("include_details"));

      .map((c: Company) => `- **${c.name}**` + (details ? `: ${c.sector}, ${c.headquarters}` : ""))
      .join("\n"),
  );
}
```

## Date parameter

A `date` parameter is a date picker. `$currentDate` with a modifier such as `-1M`, `-1w` or `-1y` keeps the default relative to today. The value is sent as `YYYY-MM-DD`.

```json title="widgets.json"

    "description": "A date picker whose default is one month before today",

    "type": "markdown",
    "endpoint": "param_date",
    "gridData": {
      "w": 20,
      "h": 8

    "source": "Invented sample data",
    "params": [
      {
        "paramName": "as_of",
        "type": "date",
        "label": "As of",

}
```

## Multi-select parameter

With `"multiSelect": true`, several options can be chosen. The values are sent joined with commas.

```json title="widgets.json"
{
  "param_multi_select": {
    "name": "Multi-select parameter",
    "description": "A dropdown in which several regions can be chosen",
    "category": "Reference backend",
    "subCategory": "Parameters",
    "type": "markdown",
    "endpoint": "param_multi_select",
    "gridData": {
      "w": 20,
      "h": 10
    },
    "source": "Invented sample data",
    "params": [
      {
        "paramName": "regions",
        "type": "text",
        "label": "Regions",
        "description": "The regions to summarize",
        "value": "americas,europe",
        "multiSelect": true,
        "options": [
          {
            "label": "Americas",
            "value": "americas"
          },
          {
            "label": "Europe",
            "value": "europe"
          },
          {
            "label": "Asia Pacific",
            "value": "apac"
          }
        ]
      }
    ]
  }
}
```

<Tabs groupId="language" queryString>
<TabItem value="python" label="Python">

```python title="python/main.py"
@app.get("/param_multi_select")
def param_multi_select(regions: str = "") -> PlainTextResponse:
    chosen = [region for region in regions.split(",") if region]
    return markdown(
        "\n".join(
            f"- {DATA['regionSummaries'].get(region, region)}" for region in chosen
        )
        or "No region chosen."
    )
```

</TabItem>
<TabItem value="typescript" label="TypeScript">

```ts title="typescript/main.ts"
"/param_multi_select": ({ query }) => {
  const chosen = (query.get("regions") ?? "").split(",").filter(Boolean);
  return markdown(chosen.map((region) => `- ${DATA.regionSummaries[region] ?? region}`).join("\n") || "No region chosen.");
}
```

## Dropdown from an endpoint

An `endpoint` parameter takes its choices from the backend. `optionsEndpoint` returns a list of `{ label, value }`.

```json title="widgets.json"

  "param_endpoint_dropdown": {
    "name": "Dropdown from an endpoint",
    "description": "A dropdown whose choices the backend serves",
    "category": "Reference backend",
    "subCategory": "Parameters",
    "type": "markdown",
    "endpoint": "param_endpoint_dropdown",
    "gridData": {
      "w": 20,
      "h": 10
    },
    "source": "Invented sample data",
    "params": [
      {
        "paramName": "company",
        "type": "endpoint",
        "label": "Company",
        "description": "The company to describe",
        "value": "alder",
        "optionsEndpoint": "company_options"
      }
    ]
  }
}
```

```python title="python/main.py"
def company_options() -> list:
```

## Dependent dropdowns

`optionsParams` sends other parameters' values with the options request. `$country` is the current value of the parameter `country`, so the city list follows the chosen country.

```json title="widgets.json"
{
  "param_dependent_dropdown": {
    "name": "Dependent dropdowns",
    "description": "A city dropdown whose choices depend on the chosen country",
    "category": "Reference backend",
    "subCategory": "Parameters",
    "type": "markdown",
    "endpoint": "param_dependent_dropdown",
    "gridData": {
      "w": 20,
      "h": 8
    },
    "source": "Invented sample data",
    "params": [
      {
        "paramName": "country",
        "type": "text",
        "label": "Country",
        "description": "The country",
        "value": "avalon",
        "options": [
          {
            "label": "Avalon",
            "value": "avalon"
          },
          {
            "label": "Borealis",
            "value": "borealis"
          }
        ]
      },
      {
        "paramName": "city",
        "type": "endpoint",
        "label": "City",
        "description": "A city of the chosen country",
        "value": "harborview",
        "optionsEndpoint": "city_options",
        "optionsParams": {
          "country": "$country"
        }
      }
    ]
  }
}
```

## Header parameter

With `"in": "header"`, the value travels as a request header named after the parameter. The name must be one a browser lets page script set, and the backend must allow it in CORS. [Header parameters](../../reference/protocols/widget-requests.mdx#header-parameters) lists the names that are not allowed.

```json title="widgets.json"
    "name": "Header parameter",

    "endpoint": "param_header",
    "gridData": {
      "w": 20,
      "h": 8
    },
    "source": "Invented sample data",
    "params": [
      {
        "paramName": "X-Desk",
        "type": "text",

        "in": "header",
        "options": [

            "label": "Credit",
            "value": "credit"
          },

            "label": "Rates",
```

## Path parameter

```json title="widgets.json"
    "description": "A parameter that fills a placeholder in the endpoint's path",
    "category": "Reference backend",
    "subCategory": "Parameters",

    "endpoint": "regions/{region}/summary",
    "gridData": {
      "w": 20,
      "h": 8
    },
    "source": "Invented sample data",
    "params": [
      {
        "paramName": "region",
        "type": "text",
        "label": "Region",
        "description": "The region in the path",
        "value": "americas",
        "options": [
          {
            "label": "Americas",
            "value": "americas"
          },
          {
            "label": "Europe",
            "value": "europe"
          },
          {
            "label": "Asia Pacific",
            "value": "apac"
```

```python title="python/main.py"
@app.get("/regions/{region}/summary")
def region_summary(region: str) -> PlainTextResponse:
    if region not in REGIONS:
        raise HTTPException(status_code=404, detail=f"Unknown region: {region}")
    return markdown(f"Path parameter: `{region}`\n\n{DATA['regionSummaries'][region]}")
```

</TabItem>
<TabItem value="typescript" label="TypeScript">

```ts title="typescript/main.ts"
[
  /^\/regions\/([^/]+)\/summary$/,
  ({ path: [region] }) => {
    if (!REGIONS.has(region)) throw new HttpError(404, `Unknown region: ${region}`);
    return markdown(`Path parameter: \`${region}\`\n\n${DATA.regionSummaries[region]}`);
  },
]
```
