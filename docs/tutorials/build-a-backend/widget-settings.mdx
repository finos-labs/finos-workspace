# Widget settings

Fields of a widget decide when FINOS Workspace fetches its data. The five widgets below show the time of their last fetch, so you can watch each setting work. They share one route shape:

<Tabs groupId="language" queryString>
<TabItem value="python" label="Python">

```python title="python/main.py"
def settings_widget(name: str) -> PlainTextResponse:
    return markdown(f"**{name}**\n\nFetched at {fetched_at()} UTC.")


@app.get("/setting_stale_time")
def setting_stale_time() -> PlainTextResponse:
    return settings_widget("Stale time: one minute")
```

</TabItem>
<TabItem value="typescript" label="TypeScript">

```ts title="typescript/main.ts"


"/setting_stale_time": () => settingsWidget("Stale time: one minute")
```

</TabItem>

## The settings

- `staleTime`: how many milliseconds a response is reused before the widget fetches again.
- `refetchInterval`: fetch again every so many milliseconds, or on a five-field cron schedule.
- `dataUpdateDisplay`: a cron schedule that tells the user when the data changes. It fetches nothing.
- `runButton`: the widget fetches only when the user selects Run.
