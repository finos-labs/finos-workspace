# Linked widgets and apps

Widgets that share a parameter can move together: choose a company in one, and the other follows. An app is a ready-made dashboard that the backend describes in `apps.json`, and it can declare such a link as a parameter group.

## Two widgets with the same parameter

Both widgets declare the parameter `company` with the same `optionsEndpoint`. That alone makes FINOS Workspace link them on a dashboard.

  "company_profile": {

```python title="python/main.py"
@app.get("/company_profile")
def company_profile(company: str = "alder") -> PlainTextResponse:
    found = company_or_404(company)
    return markdown(
        f"## {found['name']}\n\n{found['summary']}\n\n"
        f"- Sector: {found['sector']}\n- Founded: {found['founded']}\n- Headquarters: {found['headquarters']}"
    )


@app.get("/company_performance", response_model=None)
def company_performance(
    company: str = "alder", theme: str = "dark", raw: bool = False
) -> HTMLResponse | list:
    found = company_or_404(company)
    if raw:
        return found["performance"]
    rows = [
        [row["year"], row["revenue"], row["growth"]] for row in found["performance"]
    ]
    return page(
        theme,
        f"<h3>{found['name']}</h3>" + table(["Year", "Revenue ($M)", "Growth"], rows),
    )
```

"/company_profile": ({ query }) => {
  const c = companyOr404(query.get("company") ?? "alder");
  return markdown(
    `## ${c.name}\n\n${c.summary}\n\n` +
      `- Sector: ${c.sector}\n- Founded: ${c.founded}\n- Headquarters: ${c.headquarters}`,
  );
}
"/company_performance": ({ query }) => {
  const company = companyOr404(query.get("company") ?? "alder");
  if (flag(query.get("raw"))) return json(company.performance);
  const rows = company.performance.map((row) => [row.year, row.revenue, row.growth]);
  return page(query.get("theme") ?? "dark", `<h3>${company.name}</h3>` + table(["Year", "Revenue ($M)", "Growth"], rows));
}

## The app

`apps.json` returns a list of apps. This one has three tabs. On the tab Linked widgets, the group `Group 1` links the two widgets through their `company` parameter: its `type` is `endpointParam` because the parameter takes its options from an endpoint, and the group's `widgetIds`, each widget's `groups` and the parameter's `paramName` must agree. [apps.json](../../reference/schemas/apps-json.mdx) lists every field.
