# Admin CLI

The admin command line tool, `python -m scripts.workspace_admin`, manages organizations, users, data backends and widget plugins from a terminal. The script is `backend-api/backend/scripts/workspace_admin.py`. It runs inside the API container and works on the database directly, so it sends no request to the API and needs no session. The tool is therefore the way to administer a deployment before anyone can sign in.

Commands belong to a noun, such as `user` or `plugin`, and each command has its own arguments. The option `--json` prints the outcome of a command as JSON. A command that cannot do what was asked prints the reason and exits with status 1.

The sections below list the commands of each noun with their arguments. The page is generated from the parser that the script builds, through `backend-api/backend/tests/fixtures/admin_cli.json`, which a test keeps equal to it.
