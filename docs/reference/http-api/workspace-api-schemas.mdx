# FINOS Workspace API schemas

The routes of the [FINOS Workspace API](workspace-api.mdx) exchange JSON documents. This page lists the request and response models that those routes refer to, under the names that the OpenAPI document gives them in `components.schemas`. For each model it lists the properties with their type, whether they are required and what they mean. When a property holds another model, its type names that model.

The page is generated from `backend-api/backend/reference-data/openapi.json`.
