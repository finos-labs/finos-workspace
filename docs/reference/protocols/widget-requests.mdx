# Widget requests

The web app calls a backend directly from the browser, and it builds every request in `frontend/src/lib/utils/widgetRequest.ts`. This page lists what a backend receives for the definition of a widget, as [widgets.json](../schemas/widgets-json.mdx) describes it. Each table below comes from running that code on the cases that it names. [Requests that a widget sends](../../tutorials/build-a-backend/requests-from-a-widget.md) explains how the app builds a request.

## Header parameters

A header parameter's `paramName` has 1 to <WebAppValue of="headerNameMaxLength" /> characters from the HTTP token set. Three groups of names are not allowed, and names are compared without regard to case. The first group contains the names that a browser forbids page script to set: <WebAppValue of="forbiddenHeaderNames" /> and every name that starts with <WebAppValue of="forbiddenHeaderPrefixes" or />. The second group contains the names that FINOS Workspace sets itself: <WebAppValue of="reservedHeaderNames" />. The third group contains every header that the backend connection's credentials use. A header value consists of printable ASCII and has at most <WebAppValue of="headerValueMaxLength" /> characters.

Credentials belong to the backend connection and never to parameters, because the dashboard saves a parameter's value and the UI shows it. The contract refuses a parameter whose name matches one of the connection's query credentials.
