# Iframe widget protocol

An iframe widget embeds a page that can talk to FINOS Workspace through `window.postMessage`. Every message is an object with a `type` field. The messages are defined in `frontend/src/types/iframeProtocol.ts` and handled in `frontend/src/components/Widgets/Helpers/useIframeProtocol.tsx`. [Talk to FINOS Workspace from an iframe page](../../tutorials/build-a-backend/iframe-page-protocol.md) explains the order of the messages and which of them FINOS Workspace accepts.
