# Reference

Reference states how the machinery works: its interfaces, formats, settings and commands. It follows the structure of the code, it describes and does not instruct, and it gives no opinions. To learn by doing, start with the [tutorials](../tutorials/index.md). To see what a feature does, read [Features](../features/index.md). To understand how it works, read [Concepts](../concepts/index.md).
