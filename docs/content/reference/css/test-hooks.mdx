# Test hooks

The end-to-end tests find elements through attributes and ids that the components set for that purpose, and a stylesheet or a script that wants to reach the same elements can use them as well. This page lists the attributes and ids that the web app's components set as literals. They were found by scanning `frontend/src` without its tests and stories. The tests select elements with `data-testid`. A value that a component builds at run time is not listed, because the scan cannot know it. The tables are generated from the source.
