# Base properties

`frontend/src/index.css` declares a second set of properties, in the `base` layer, on `:root` and `.dark`. They follow the naming of the shadcn/ui components that the app's design system is built on, and Tailwind maps them to utilities such as `bg-background`, `text-foreground`, `border-border` and `ring-ring`. The tables are generated from the stylesheet and from the frontend source.

Because these declarations are in a layer, a stylesheet that is not in a layer overrides them whatever its position.

The brand, font and scale properties of the same file are on [Brand colour, font and text size](brand-font-size.mdx).
