# Brand colour, font and text size

The brand colour, the font and the text size are custom properties like the others. The base stylesheets declare them, and the theme stylesheet that `WL_STYLESHEET` names loads after the base and overrides them (see [How to create a theme for the web app](../../how-to/customize/create-a-theme.md)). So does the preset that an admin applies ([Theme presets](theme-presets.mdx)).

| Property | Declared in | Value |
|---|---|---|
| `--color-main-100` | `tokens.css` | `#0086bf`, FINOS Dark Blue: the brand colour. |
| `--color-main-50` | `tokens.css` | `#00b5e2`, FINOS Light Blue. |
| `--color-main-200` | `tokens.css` | `#005e8a`, the darker step. |
| `--color-main-contrast` | `tokens.css` | `var(--color-light-100)`: the colour of text on brand-coloured controls. |
| `--brand-main`, `--brand-lighter`, `--brand-darker` | `index.css` | `var(--color-main-100)`, `var(--color-main-50)` and `var(--color-main-200)`. |
| `--font-family` | `index.css` | `"Montserrat"`. |
| `--text-scale` | `index.css` | `1`, and `1.25` while `<html>` has `data-font-size="large"`. |
| `--radius` | `index.css` | `0.5rem`. |

## The brand colour

The three steps hold the colours as given and are independent: changing `--color-main-100` alone leaves the two other steps as they are. A theme that has a brand colour of its own sets all three, and can derive the shades from it with `color-mix`, which is what the preview panel prints:

```css
:root {
  --color-main-100: <hex-colour>;
  --color-main-50: color-mix(in srgb, var(--color-main-100) 70%, white);
  --color-main-200: color-mix(in srgb, var(--color-main-100) 70%, black);
  --color-main-contrast: var(--color-light-100);
}
```

The first `color-mix` moves the colour 30% of the way to white, and the second multiplies each channel by 0.7. The three `--brand-*` aliases follow the three steps.

`--color-main-contrast` is a property of its own: a theme that makes the brand colour light sets it to a dark colour, such as `var(--color-light-700)`. `--btn-primary-label`, `--tab-filled-primary-text-active` and `--copilot-mention-label` read it.

Components read the shades through the `main` colour utilities, such as `bg-main-100`, and through the `brand` utilities: `bg-brand-main`, `bg-brand-lighter` and `bg-brand-darker`.

## The font

`index.css` sets the font of `:root` to `var(--font-family)` followed by `system-ui`, and the font of `body` to `var(--font-family)` followed by `sans-serif`. The Tailwind class `font-wl` uses the same property. The app ships Montserrat, Inter and Roboto, declared with `@font-face` (see [Selectors](selectors.mdx)). Any other family name works only where the viewer's device has that font.

## The text scale

The user's Font size setting, `medium` or `large`, is written to the `data-font-size` attribute of `<html>`. The rule `:root[data-font-size="large"]` sets `--text-scale` to `1.25`.

`--text-scale` multiplies the font size of every Tailwind text size (`text-2xs` to `text-9xl`), and the font size and line height of the typography classes `title-*`, `subtitle-*` and `body-*`. A rule that gives a size in fixed units does not scale.

## Radius

`rounded-lg` is `var(--radius)`, `rounded-md` is that minus 2px, and `rounded-sm` is that minus 4px.

## The theme editor

Users of type Admin change these properties on Admin → Theme → Presets: the brand colour and its shades, the contrast colour, the font and the radius are in the Brand group. "Derive from brand color" sets the two shades and the contrast colour from the brand colour: the shades are the `color-mix` declarations above, and the contrast value is chosen from the relative luminance of the colour, `var(--color-light-700)` above 0.22 and `var(--color-light-100)` otherwise. See [Theme presets](theme-presets.mdx).
