# Semantic properties

The properties that components read. Each one is declared on `:root` for the light theme and on `.dark` for the dark theme in `frontend/src/styles/tokens.css`, and its value is usually a `var()` of a [palette](colour-palette.mdx) property. The tables are generated from that file and from the frontend source.

- **Class names** are the Tailwind utilities that read the property. Tailwind maps a utility name to a property in `frontend/tailwind.config.ts`, so `bg-btn-primary-bg` paints with `--btn-primary-bg`. The list shows the forms that the source uses, with the most used first.
- **Used by** names the files that use the property most, the number of uses, and the rules or scripts that read it without a utility.
- A property that nothing reads is listed at the end of the page. Changing it has no effect.

The theme and cascade rules are on [Theme scopes and cascade](theme-scopes.mdx).
