# Backend settings

The API, the worker and the init job read their settings from the environment and from `backend-api/backend/envs/.env`. The `Settings` class in `backend-api/backend/utilities/config.py` declares them, in groups. A variable name is the setting's name, matched without regard to case, with no prefix. A setting without a default is required: the process does not start without it.

The tables are generated from the `Settings` class. A description comes from the comment above the variable in `backend-api/backend/envs/.env.example`, and a setting that has no comment there says so. The data is `backend-api/backend/tests/fixtures/settings.json`, which a test keeps equal to the class.
