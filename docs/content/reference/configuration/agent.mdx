# Ines and its MCP server

The agent and its MCP server read their settings from the environment and from `agent/.env`. Compose passes the file to both services.

## Variables read by name

The variables that the code under `agent/src` and `agent/mcp-server/src` reads as `process.env.NAME`. A description comes from the comment above the variable in `agent/.env.example`.

## In `.env.example` and not read by name

Variables that `agent/.env.example` lists and that the code does not read as `process.env.NAME`.
