# Ines and its MCP server

Ines is the built-in agent of Workspace. It runs as two processes: the agent itself, and an MCP server that offers it tools. Both read their settings from the environment. On a local stack, the file `agent/.env` supplies the settings, and a deployment supplies the same variables through its own configuration.

## Variables that the code reads

This section lists the variables that the code under `agent/src` and `agent/mcp-server/src` reads as `process.env.NAME`. Each table row shows the variable, its type and its default, and the description comes from the comment above the variable in `agent/.env.example`.
