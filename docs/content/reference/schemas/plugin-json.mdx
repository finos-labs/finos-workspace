# plugin.json

Every widget plugin carries a manifest named `plugin.json`, which describes the plugin, the permissions that it asks for and the widgets that it contributes. This page lists the JSON Schema of the manifest. [Plugin package and manifest](../plugins/package-and-manifest.md) explains what each part means and how a package is laid out.

The `Manifest` model in `backend-api/backend/api/widget_plugins/manifest.py` defines the manifest. The schema below is the one that the model produces, followed by the models that it refers to. The page is generated from `backend-api/backend/tests/fixtures/plugin_manifest_schema.json`, which a test keeps equal to the model.
