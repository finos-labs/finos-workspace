# apps.json

An app is a template that a backend offers: a set of tabs of widgets with their layout, which a user can open as a dashboard. A backend lists its apps in a file named `apps.json`. The file is an array, and each element describes one app template.

This page lists the JSON Schema (draft-07) that the file must satisfy. The script `frontend/scripts/generate-apps-schema.ts` writes the schema to `frontend/apps-schema.json`, and the page is generated from that file. The widgets that an app places are defined in [widgets.json](widgets-json.mdx).
