# Database tables

The tables that the SQLAlchemy models in `backend-api/backend/api/models` declare. Alembic migrations in `backend-api/backend/alembic/versions` create and change them. Column types are those of the SQLAlchemy types, as the models name them.

The page is generated from `backend-api/backend/tests/fixtures/database_schema.json`, which a test keeps equal to the models.
