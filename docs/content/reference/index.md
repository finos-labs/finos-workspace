# Reference

Reference states how the machinery works: its interfaces, formats, settings and commands. It follows the structure of the code, describes and does not instruct, and gives no opinions.

To learn by doing, use the [tutorials](/tutorials). For a task, use the [how-to guides](/how-to). For the reasons behind the design, read the [explanation](/explanation).
