# Workspace API

The routes of the API, grouped by the tag that the router gives them. The API serves no interactive documentation: it sets `docs_url`, `redoc_url` and `openapi_url` to `None`. The summary of a route is derived from the name of its function. Request and response types link to [Workspace API schemas](workspace-api-schemas.mdx).

The page is generated from `backend-api/backend/tests/fixtures/openapi.json`, which a test keeps equal to the document that `app.openapi()` builds, without `/metrics`. That route exists only when the `PROMETHEUS` setting is on, and it serves the Prometheus metrics.
